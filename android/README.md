# Somatic AI SDK · Android

版本：0.1.7 / build 21。将随包 `repository` 添加为 Maven 仓库，使用 `com.somaticai.somaloop:sdk:0.1.7`；研究库坐标为 `com.somaticai.somaloop:experimental:0.1.7`。步骤见 [Android / Java 接入](../docs/Android接入.md)。

第三方运行时依赖列于 [dependencies.json](dependencies.json)，由 Gradle 解析。[Demo](SomaLoopSDKDemo/README.md) 演示连接、读取、采集、停止和导出。
