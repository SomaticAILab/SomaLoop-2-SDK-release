# 验收状态

本文件适用于 **0.1.6-beta / build 20 私有评估候选**，暂不公开发布。该构建的实际通过、跳过、失败和制品匹配结果以包根目录 [release-report.json](../release-report.json) 为准，构建身份见 [build-identity.json](../build-identity.json)。不要将旧版测试计数或其他提交的成功结果套用于本包。测试与验收结果不改变 [SDK 评估许可](../LICENSE) 的范围。

## 软件与制品

验证报告分别列出 iOS 平台测试、Android SDK 测试、Java API、独立二进制消费者、工具测试及 Demo 构建结果。独立消费者验证的是本次真实 XCFramework/AAR 输入；软件模拟和构建成功不代表手机 BLE 或真实生理数据验证。

收到私有候选包后，核对随附的压缩包校验值，再核对包内 [SHA256SUMS](../SHA256SUMS)。主库和研究库保持同一构建，运行时指纹与报告一致后再开始接入验收。

## 接入方验收

先记录 SDK 版本、构建指纹、系统版本、设备固件和本轮实际连接/佩戴条件，再逐项记录预期、观察、部分结果及停止状态。历史清除须先确认数据处置范围；采集和马达须由本轮使用者显式发起，旧时刻的设备状态不能替代当前确认。

应分别完成基本连接与读取、主动测量取值、停止和取消、断连与恢复、前后台及重启、长时间采集和导出一致性。保留失败和未验证项，不因后续成功而覆盖原始记录。
