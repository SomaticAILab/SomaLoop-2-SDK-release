# 远程依赖与版本锁定

本包版本为 0.2.0 / build 41。仓库根目录 `Package.swift` 引用本包两份 XCFramework，保留随包本地 Package 用法。

## Swift Package Manager

发布仓库 URL 为 `https://github.com/SomaticAILab/SomaLoop-2-SDK-release.git`。在 Xcode 添加远程依赖时选择 Commit，填入**该次已发布制品对应的完整提交 SHA**，添加 `SomaLoopSDK`，需要研究接口时再添加 `SomaLoopExperimental`。提交 App 的 `Package.resolved`；不要依赖 main 浮动状态。仓库根清单使用随 Git 取回的 `binaryTarget(path:)`，无需手工拷包，但会下载发布仓库；不是独立 ZIP 的 URL/checksum 分发。

使用本次 Release 的 `v0.2.0-build41` 所指向的发布仓库完整提交 SHA 锁定依赖，并核对同一提交的 `build-identity.json`。`v版本-build构建号` 不是 SwiftPM 的语义版本范围，不使用 `from:`；旧版本的 `distribution-update.json` revision 不用于本版本。

## Maven

将以下仓库加入 `settings.gradle.kts` 的 `dependencyResolutionManagement.repositories`：

```kotlin
exclusiveContent {
    forRepository {
        maven {
            name = "SomaLoopRelease"
            url = uri("https://raw.githubusercontent.com/SomaticAILab/SomaLoop-2-SDK-release/v0.2.0-build41/android/repository")
        }
    }
    filter { includeGroup("com.somaticai.somaloop") }
}
google()
mavenCentral()
```

在模块 dependencies 中使用 `implementation("com.somaticai.somaloop:sdk:0.2.0")`；研究模块可选 `implementation("com.somaticai.somaloop:experimental:0.2.0")`。仓库 tag 与坐标都固定版本；启用 dependency locking，提交 lockfile，并按该版本 SHA256SUMS 配置 dependency verification。不使用 `+`、SNAPSHOT 或 main URL。

公开仓库不需要凭据，不把 token 写入项目。网络受限时按开发机器已有代理配置工具，或使用完整发布包内的本地 repository。实际二进制、构建指纹与验证范围见该版本发布报告；清单解析成功不等于 iOS 编译或手机验收通过。
